# A Little Question ❤️

A simple interactive date invitation website.

## GitHub Pages

1. Upload `index.html` to the root of your GitHub repository.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, select:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/ (root)**
4. Click **Save**.
5. Wait a few minutes and open the generated GitHub Pages URL.

The main page must be named exactly `index.html` and must be in the selected publishing folder.
